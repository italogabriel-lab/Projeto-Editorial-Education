# Curriculum Macro Adapter

Adapta grades curriculares de Belas Artes para semanas com tema central e dois desdobramentos.
O tema `x.1` deve gerar palavras-chave estruturantes para `x.2` e `x.3`.

## Uso

Use quando uma lista de temas precisar virar uma sequência semanal padronizada:

```text
1.1	Tema central
1.2	Primeiro desdobramento
1.3	Segundo desdobramento
```

`1.2` e `1.3` devem nascer de palavras ou aspectos explícitos do tema `1.1`.

## Entradas comuns

- `1 - Curriculo Macro`.
- `0 - Assuntos para trabalhar no ano.md`.
- Pedido de criação de cópia com `novo padrão` no nome.

## Saída esperada

Lista organizada, sem plano de aula completo, sem objetivos e sem avaliações.
